# Java-Basics

## About the Project
This project demonstrates the installation of JDK
and configuration of the Java development environment.

## Technologies Used
- Java
- JDK 25
- VS Code

## Project Structure
- HelloWorld.java

## How to Run

Compile:
javac HelloWorld.java

Execute:
java HelloWorld

## Output
Hello World!
Java Environment Configured Successfully!

## Learning Outcome
Learned how to install JDK, configure JAVA_HOME
and PATH environment variables, and execute
a Java program successfully.
